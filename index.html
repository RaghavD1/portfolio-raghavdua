CyberTwin

What it is: A distributed backend system that ingests structured system logs and routes them through rule-based + ML-assisted anomaly detection pipelines. Multi-agent architecture where each agent handles a specific detection domain (auth failures, traffic spikes, payload anomalies).

Why it's different: Most security tools are monolithic. CyberTwin separates ingestion, detection, and response into independent services, making each component testable and replaceable independently.

Log Ingestion → Agent Router → Detection Layer → Response API

Fake News Detection — BERT + Baseline

What it is: An NLP classification system built to compare two approaches — fine-tuned BERT vs. TF-IDF + Logistic Regression — on the same labeled news dataset. The goal was not just accuracy but understanding where each model fails and why.

Results (on validation set): BERT achieved 98.4% accuracy; TF-IDF baseline achieved ~91%. Gap was largest on politically-framed neutral language — where semantic context matters more than keyword frequency.

Context on the 98.4%: This is on a standard academic dataset (not a scraped real-world corpus). Real-world performance would be lower — acknowledged.

Python PyTorch BERT Scikit-learn TF-IDF HuggingFace
Sept — Nov 2025 Dataset: standard academic corpus · Validation split: 20%

NLP Text Classification Pipeline

What it is: A reusable NLP pipeline for text classification tasks. Handles raw text input → cleaning → TF-IDF vectorization → model training → evaluation output. Built to be dropped into any classification task without rewriting the preprocessing layer.

What I learned: Preprocessing decisions (stop word removal, stemming vs. lemmatisation) affected final accuracy more than model choice on small datasets. Documented findings in the README.
